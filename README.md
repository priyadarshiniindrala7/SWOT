# Goal-Driven SWOT Analyzer

A minimalist decision-support application designed to turn traditional SWOT analysis into actionable prioritization. The platform determines whether to leverage strengths or address weaknesses based on the user's immediate goal, time constraints, and priority level.

---

## Philosophy

> *"IF THE OUTPUT IS THE GOAL YOU NEED TO PLAY BY YOUR STRENGTH BUT IF IMPROVEMENT IS THE GOAL YOU NEED TO WORK ON YOUR WEAKNESS"*

---

## Overview

Traditional SWOT matrices organize internal and external factors into quadrants, but often leave the user without a clear next action. This application bridges that gap by applying a goal-oriented decision framework to the user's inputs:

- **Output Mode:** Prioritizes Strengths and Opportunities to maximize immediate, reliable execution.
- **Improvement Mode:** Focuses on mitigating Weaknesses and guarding against Threats to build long-term capability.

---

## Key Features

- **Minimalist 4-Box Input:** Dedicated entry fields for Strengths, Weaknesses, Opportunities, and Threats.
- **Goal Mode Toggle:** Explicit selection between *Output* (results-driven) and *Improvement* (growth-driven).
- **Constraint Modifiers:** Configurable time availability and importance metrics to refine recommendation urgency.
- **Actionable Focus Engine:** Generates prioritized focus areas based on selected parameters.

---

## How It Works

1. **Input Generation:** Populate the four SWOT quadrants.
2. **Context Selection:**
   - Select primary goal mode (**Output** vs. **Improvement**).
   - Set the available time horizon (Short-term / Medium-term / Long-term).
   - Define the priority/importance level.
3. **Synthesis:** The application processes the weighted parameters and returns a targeted action plan specifying the exact areas requiring immediate attention.
